# OmniRig COM wrapper (generated)

`OmniRig.h` and `OmniRig.cpp` are the Qt ActiveQt wrapper for the OmniRig
COM interface, generated by Qt's `dumpcpp` (Qt 5.15.19) from the type
library embedded in `OmniRig.exe` (OmniRig 2.x, https://www.dxatlas.com/OmniRig/).

They are committed so Windows builds don't need `dumpcpp` or an installed
OmniRig. That is what makes cross-compiling the Windows installers with
MXE on Linux possible. CMake uses them automatically on Windows builds.

Edits after generation (needed for building on case-sensitive systems):

- `OmniRig.cpp`: `#include "OmniRig.h"` instead of the absolute build path
- `OmniRig.cpp`: `#include <oaidl.h>` instead of `<OAIdl.h>`
- LF line endings

To regenerate (on Windows, with OmniRig installed), configure with
`-DOMNIRIG_TYPE_LIB="C:/Program Files (x86)/Afreet/OmniRig/OmniRig.exe"`
and copy `OmniRig.h` / `OmniRig.cpp` from the build directory here, then
re-apply the edits above.
